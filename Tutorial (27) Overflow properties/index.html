CSS Overflow Property

Visible

This is a very long paragraph. The extra content can come outside the box because overflow is visible.

Hidden

This is a very long paragraph. Extra content will be hidden when it goes outside the box.

Scroll

This is a very long paragraph. Scrollbars will appear so you can scroll and read the extra content.

Auto

This is a very long paragraph. Scrollbar will appear only when the content actually overflows.
